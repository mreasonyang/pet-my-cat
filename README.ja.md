# うちの猫がゲスト参加（我家猫来客串）

真上から全身がはっきり写った写真があれば、ブラウザ上で背中をなでたり、しっぽを揺らして遊べる猫に仕立てられます。正面や横からの普段の写真しかない場合でも、画像生成ツールで写真を参考に真上からの姿勢を作ることができます。写真を端末の外に出したくない場合やローカルの画像生成ツールがない場合は、背中としっぽが写った俯瞰写真を1枚追加するだけで実写切り抜きルートに進めます。できあがった猫は、開いている[本家サイト](https://pet-the-cat.pages.dev/)のタブに一時読み込みして遊ぶことも、オフラインの個人用HTMLとして直接開くこともできます。一時ビューを閉じるか本家サイトを再読み込みすれば、いつでも元のページに戻ります。

## はじめかた

1. **スキルフォルダの配置**：このリポジトリをクローンするか、最新リリースの [`pet-my-cat.zip`](https://github.com/mreasonyang/pet-my-cat/releases/latest/download/pet-my-cat.zip) を展開してフォルダ名を `pet-my-cat` に揃え、`pet-my-cat` フォルダ丸ごとプロジェクトの `.agents/skills/` に配置します（展開後に `pet-my-cat/SKILL.md` を直接エージェントに読ませても使えます）。詳しくは [Codex スキルディレクトリ案内](https://developers.openai.com/codex/skills/) を参照してください。
2. **写真を添えて呼び出す**：実際の毛並みや模様をそのまま残したい場合は、耳・背中全体・しっぽの付け根から先までが見える真上からの写真が最適です。手元の写真を添えて、次のひとことをコピーしてエージェントに伝えてください。

   - **真上からの写真がある場合**：
     > $pet-my-cat を使って、この猫の写真を猫なでサイトに一時追加して現在のタブで遊べるようにして。

   - **普段の写真から真上ポーズを生成する場合**：
     > $pet-my-cat で「きなこ」を猫なでサイトに一時追加して。この2枚の写真を参考に真上からの姿勢を作って、見えている模様は残し、写っていない背中の柄は近い雰囲気で補って。

3. **現在のタブまたはオフラインで遊ぶ**：エージェントがローカルで個人用HTMLを組み立てます。ブラウザ操作機能がある環境では、開いている本家サイトの現在のタブへ直接読み込めます。手動でファイルを選ぶ場合は、同梱の[ブックマークツール](assets/current-tab.html)を開き、画面の案内に従ってブックマークバーに登録したうえで、本家サイトのタブで個人用HTMLを選択してください。デスクトップブラウザで個人用HTMLを直接開いてオフラインで遊ぶこともできます。一時ビューを閉じれば元の猫に戻り、本家サイトを再読み込みすればゲスト表示はクリアされます。

## 輪郭の部分修正

猫の毛色と爪とぎ・マット・床の色が近いとき、なでている最中に小さな背景のかけらが毛と一緒に動くことがあります。その場合は「背中の上あたりに爪とぎの模様が少し残っている」のように具体的な場所をエージェントに伝えてください。元の写真を拡大してその部分の境界を見比べ、背景だけを削り直した更新版の個人用HTMLを作成します。

## 対応言語と表示の範囲

スキル自体は `zh-CN`（簡体字中国語）・`ja`（日本語）・`en`（英語）に対応しています。

- **会話とスキル固有の案内**：エージェントとの会話はユーザーの言語に合わせます。個人用HTMLを作成する際の言語指定（スキル固有の案内文や、名前を省略したときのデフォルト名「我家的猫」／「うちの猫」／「My cat」を制御）は、明示的な希望があればそれを優先し、なければ会話の言語に追従します。飼い主が指定した猫の名前はそのまま表示されます。
- **ブックマークガイド**：[ブックマークツール](assets/current-tab.html)とそのダイアログはブラウザの言語を自動選択し、画面上で手動切り替えも可能です。同じ言語の個人用HTMLと組み合わせることで案内表示が揃います。
- **本家サイトの日本語UIはそのまま保持**：オンラインの[本家サイト](https://pet-the-cat.pages.dev/)は原作者によって運営されています。公開サイトでもローカルの個人用セッションでも、猫の切り替え・体型・鳴き声・ショートカットといった本家サイト本来のゲームUIは元の日本語のまま維持され、本スキルがサイト全体のゲームUIを翻訳することはありません。

## ローカル処理・AI利用とプライバシー・ライセンス

- **ローカル組み立てと必要に応じたAI同意**：個人用HTMLは端末上の Python 3 で組み立てられ、写真処理の補助ツールは Pillow を使用します。実写の切り抜きはすべてローカルで完結します。普段の写真から真上ポーズを生成したり欠けている部分を補完したりするためにクラウドの画像生成サービスを使う場合は、送信先の具体的なサービス名を事前に伝え、同意を得てから実行します。
- **本家サイトへのアップロードなし**：猫の写真や切り出したレイヤー、作成した個人用HTMLはすべてお使いの端末内に留まり、本家サイトへアップロードされることはありません。スキルを共有する際はスキルパッケージのみを共有し、各自の写真と個人用HTMLは手元で個別に保管してください。
