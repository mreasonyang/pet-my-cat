# 照片分层与姿势对齐

选一张接近垂直俯拍、自然趴卧的工作图。耳朵、背、臀和从根到尖的尾巴应清晰可见。有合适实拍图时直接使用。多个候选中，优先用尾巴离开臀部后一路可分辨、没压住背部的那张。

在本机私有目录留存原图、工作图、标注和导出的图层，只编辑副本。以下抠图、定点和验收均由 agent 完成。

## 参考图生成与验收

把用户提供的同一只猫的照片作为图像输入。先从图中记录两三个最容易辨认的特征，例如左右耳的颜色、背斑的位置或尾尖花色。能看出哪几项就记录哪几项。只有正脸照时，背面花纹属于推测，用户想要忠实还原时可先补背照。

使用能接收参考图的生成或编辑工具。用户要求照片留在设备上时，看图、分割和生图都选实际在本机运行的工具。若生图必须使用云端服务，告诉用户参考图会发给哪个服务，按其选择执行。已有针对该服务和这些照片的明确选择可直接沿用。缺少合用工具时，可请用户补俯拍照或提供已分好的图层，走本地组装流程。

- **只缺局部**时，在原图副本上限定补绘区域。工具支持蒙版时圈出缺失处和少量接缝，合成时从原照贴回选区外的身体，逐一比对可见斑纹。
- **需要换视角**时，一次生成整只猫，身体和尾巴共用这一张图的花纹、光线和比例。可以用下面这段提示，再填入参考照中确实可见的特征。

  > 参考所附照片中的同一只猫，制作一张写实的垂直俯视全身图。自然趴卧，头向左，臀向右，耳朵和整个背部清楚。尾巴从臀部自然伸向右侧，与身体只在尾根相接，让尾尖完整入画。保留参考照里的体型、左右不对称的斑纹和毛色。用柔和均匀的光，四周留白，背景透明。

生成后保存实际图片文件，和原照并排核对左右斑纹、尾根到尾尖的色带、耳朵形状和四肢数量。看不见的区域在交付时注明为近似。若已知斑纹偏移或尾巴重叠，针对该处修正，再用下方流程导出两层。带真透明通道的图可保留原有细毛边缘，带背景的图沿轮廓抠出。

## 交给构建器的图层

| 文件 | 画布 | 对齐 |
| --- | --- | --- |
| `body.png` | 1517×935 RGBA PNG | 猫头在左，臀在右。两耳根之间的头顶中心约在 `(200, 445)`，尾根关节在 `(1136, 424)`。保留臀部与尾根的一小块固定毛皮，移出可动尾段。保留整张透明画布。 |
| `tail.png` | 684×200 RGBA PNG | 尾巴沿实际中心线的弧长展开为水平条带，`y=100` 是中心线，根在 `(20, 100)`，尖向右。`x=0…19` 是根部搭接。`x≈646` 是最后一个骨架取样点，需要有尾尖内侧的实体像素，圆尖在其后收至约 `x=658`。 |

原渲染器按 `x=20+弧长（画布像素）` 取样，从 `y=100` 向两侧读取连续的 alpha（阈值 85），再把图条弯回它的骨架。渲染时尾层在身体后面。在臀内选尾根关节，身体遮住尾条左端，并在关节往尾巴方向留少许交叠。静止和摆动时都应看不到断缝或重复尾段。

## 在本机标注和导出

1. 打开按 EXIF 方向转正的工作图，用图像工具读像素坐标。若只有缩放预览，按预览比例和偏移换回工作图的实际坐标。照片原件保持原样。必要时在本地转存 HEIC 等格式为正常方向的 JPEG 或 sRGB PNG，再在转存图上标注。
2. 沿身形圈出猫身，保留耳朵、可见的腿和臀部到尾根的平顺边界。抠掉地板、投影和要移动的尾段。纯色背景也可以直接沿轮廓点选。用 Pillow 在预览副本上叠画轮廓和定点，放大检查耳朵、长毛及尾根再修正。
3. 标出头顶中心和尾巴的截面中心，从臀内的尾根关节一路到尖。弯处和宽度变化处加点。每个宽度沿当地中心线的垂直方向量两侧的全宽。尾尖内侧最后一个截面放在圆尖开始收拢的位置，给它可见的宽度。最后一个点落在尾尖最外缘，宽度为零。遇到转弯紧、前后两段靠近或长毛轮廓不对称时，加上单独的尾部蒙版以排除相邻毛皮和背景。

若已有本地分割或绘图工具，可用它画软边蒙版交给脚本，也可以直接导出两张满足规格的图层。在编辑器里先等比旋转缩放身体，让头和尾根对齐，再沿尾巴每段的局部法线取截面，把弯尾逐段展平。保持原照纹理和沿途宽窄变化。

### Pillow 辅助脚本

在私有工作目录运行下面的命令，`skill_dir` 指向技能目录。需要 Python 3.8 或更新版和 Pillow 9.1 或更新版。如果系统 Python 缺少 Pillow，可在工作目录建临时虚拟环境安装 Pillow，再用该环境的 Python 执行。脚本读取本机图像和标注，创建新的 `layers/` 目录。

```sh
python3 "$skill_dir/scripts/prepare_photo.py" cat.jpg layout.json layers
```

把 agent 量到的坐标写入 `layout.json`。坐标单位为转正后原尺寸工作图的像素，左上为原点，x 向右、y 向下。`head` 是头顶点。`body` 是沿轮廓顺序排列的多边形。`tail` 是从根到尖排列的 `[x, y, 全宽]`，第一个点同时用作身体对齐的尾根，倒数第二个点对到条带 `x=646`。以下示例采用 1200×900 的合成工作图。

```json
{
  "head": [200, 410],
  "body": [[100, 390], [131, 305], [189, 345], [290, 310], [638, 278], [806, 301], [907, 367], [924, 415], [890, 487], [738, 540], [316, 554], [158, 510], [109, 517]],
  "tail": [[885, 398, 74], [960, 403, 70], [1040, 420, 68], [1093, 457, 63], [1113, 510, 58], [1112, 575, 54], [1084, 625, 48], [1040, 662, 40], [1010, 677, 30], [998, 681, 0]]
}
```

`body` 也可以填同尺寸的灰度蒙版路径，如 `"body-mask.png"`。可选的 `tail_outline` 同样接受多边形或灰度蒙版路径，应包括藏在臀下的搭接段。蒙版白色保留、黑色透明、灰色表示边缘透明度，相对路径以 JSON 所在目录为准。提供尾蒙版时，标注的截面宽度要容纳蒙版两侧的毛边，以免条带裁掉细毛。

脚本对身体做旋转与等比缩放，尾条沿截面从照片重采样。尾巴长度适配固定骨架，特别短的尾巴会被明显拉长。尾巴太宽时脚本会报告收窄。输出后在浅色和深色底上复查透明边缘、花纹方向、臀部搭接和尾尖。最终叠图应保持耳朵与身体比例，条带的根、尖内侧中心应有内容，尖后和上下有透明余量。接入后在静止、拨尾时各查看一次。边缘沾了背景或尾尖过细时，先修正蒙版和截面，重新输出到新目录。

## 毛色与背景接近时的修边

当背景和猫毛颜色接近时，缩小看整只猫，容易把一小块背景当成毛。检查背线、腹线、肩部和其他接触背景的位置，找突出的硬边、笔直的木纹或成排的抓板纹路。回到原照同一位置，看纹理是否从周围背景连续伸进轮廓，还是沿毛流收成毛尖。暂时保留难以确认的细毛，先修能从原照辨认的背景。

在转正后的原尺寸工作图上选一个包含内侧毛发、可疑边缘和外侧背景的小裁框。沿用之前的 `layout.json`，把预览导出到新目录。以下坐标变量为本次裁框的像素值，右、下边界不包含在框内。可重复传入 `--inspect-box` 对照几处。

```sh
python3 "$skill_dir/scripts/prepare_photo.py" cat.jpg layout.json layers-review \
  --inspect-box "$left" "$top" "$right" "$bottom"
```

打开 `layers-review/edge-01.png`。从左到右是同一裁框的原照、浅底抠图和深冷色底抠图。确认有残留时，给布局加上可选的 `body_trims`。里面每个多边形圈出一块背景。靠猫的一边沿着可辨认的毛尖描点，另一边在外侧背景闭合。多段残留分别画小块，留存原蒙版。下面是一个新增字段的例子，实际坐标要在本次工作图上量取。原蒙版是多边形或灰度图都适用。

```json
{
  "body_trims": [[[360, 306], [378, 305], [390, 302], [390, 295], [360, 295]]]
}
```

用同样的裁框导出到另一新目录。填写修剪区后，对照图右侧会多出修前的浅底和深底图。比较同底色的修前与修后轮廓，确认抓板纹路消失，旁边的浅色毛尖和深色花纹仍在。如果裁掉了真实毛尖，回到原蒙版收小修剪范围。

还有一种情况是毛尖形状完整，半透明像素却混进了木地板的颜色。用原照确认后，可在图层副本上参考内侧同一撮毛的颜色，只校正沾色的几处毛尖，保留其透明度。换到浅底和深底各看一次。

最后用本轮确认的 `body.png` 和 `tail.png` 重新生成个人网页，在实际大小下看一遍静止和抚摸时的轮廓。

## 照片缺少可用尾巴或俯拍角度

- 想保留真实尾纹时，可补同一只猫从尾根到尾尖可见的照片。若补图只有尾部，可在本地编辑器里按尾根方向和宽度接到身体照片的工作副本上，再标注两层并检查接缝。用户接受推测时也可按上方流程局部补绘。
- 用户愿意先看身体效果时，可在布局里省略 `tail`，改用 `"rump": [x, y]` 指定臀部内侧的对齐点。脚本会导出透明的尾层占位。只在构建器能关闭尾部绘制及命中时用于互动，否则把 `body.png` 作为静态预览。
- 侧拍或透视明显时，可以走参考图生成、补俯拍实照或使用原图做静态预览，按用户对还原度的要求选择。
